Over deze module

Blok 3 bouwt voort op Python 1 (programmeren) en Python 2 (data-analyse en machine learning). Waar je eerder analyseerde in notebooks, bouw je nu een product: iets dat een ander kan draaien en dat een financiële vraag beantwoordt — een dashboard, een geautomatiseerd rapport of een model achter een simpele interface.

Niveau: creëren. Je brengt alles uit blok 1 en 2 samen tot een werkend, bruikbaar dataproduct. De rode draad is de weg van analyse naar product; Streamlit en DuckDB zijn de belangrijkste gereedschappen, met het Data Science Handbook (VanderPlas) en Python for Data Analysis (McKinney) als verdieping.

Leerdoelen:

  1. Je zet een analyse om in een herbruikbaar, draaibaar product met een duidelijke gebruiker en vraag.
  2. Je bewaart en bevraagt data in een database (DuckDB) en bouwt een herhaalbare datapijplijn.
  3. Je maakt data en modellen zichtbaar en bruikbaar via een dashboard of geautomatiseerd rapport.
  4. Je beoordeelt de betrouwbaarheid van je product: reproduceerbaar, controleerbaar en gedocumenteerd.
  5. Je levert een eind-tot-eind financieel dataproduct op en verantwoordt je keuzes.
