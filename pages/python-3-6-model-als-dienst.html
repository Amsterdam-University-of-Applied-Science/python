Les 3.6 — Een model als dienst

Een model uit Python 2 bruikbaar maken voor een niet-technische gebruiker: invoer erin, voorspelling eruit.

Terugblik

In les 3.5 automatiseerden we een rapport.

Vandaag

We zetten een getraind model achter een simpele interface, zodat iemand zonder code een voorspelling kan opvragen.

Theorie

Onderwerp Toelichting Bron/notebook
Model bewaren & laden Een getraind model opslaan en hergebruiken —
Interface eromheen Invoer → voorspelling, via Streamlit docs
Begrijpelijke uitvoer De voorspelling uitlegbaar tonen —

Library — scikit-learn (opslaan/laden) & Streamlit. Documentatie

Verdieping:

  • Reitz, K., & Schlusser, T. (z.d.). The Hitchhiker’s guide to Python. Structuring your project

Praktijk — class assignment

Neem een model uit Python 2 en bouw er een simpele interface omheen waarin een gebruiker invoer geeft en een voorspelling terugkrijgt — met een begrijpelijke toelichting.

Aanpak: model + invoervelden kiezen (10) · interface — agent (20) · testen met realistische invoer (15) · toelichting (5).

Inleveren: notebook of app met je product en een korte toelichting — max 1 A4, volgens de algemene inlevereisen (link volgt).
