Les 3.2 — Data bewaren

Van losse CSV-bestanden naar een database die blijft bestaan en die je steeds opnieuw kunt bevragen.

Terugblik

In les 3.1 maakten we van een analyse een herbruikbaar script.

Vandaag

We slaan data op in DuckDB (een database zonder server) en bevragen die met SQL. Waarom is dat beter dan een CSV inlezen?

Theorie

Onderwerp Toelichting Bron/notebook
DuckDB Een embedded database; data die blijft docs
SQL-basis Selecteren, filteren, aggregeren met queries —
pandas ↔ database DataFrames schrijven naar en lezen uit DuckDB —

Library — DuckDB. Documentatie

Verdieping: McKinney, Python for Data Analysis — hfdst. 6: Data Loading, Storage & File Formats

Praktijk — class assignment

Laad een dataset in een DuckDB-database en beantwoord met SQL een financiële vraag die meerdere keren herhaalbaar is.

Aanpak: data in DuckDB laden (15) · SQL-query schrijven — agent (10) · resultaat controleren (20) · toelichting (5).

Inleveren: notebook of app met je product en een korte toelichting — max 1 A4, volgens de algemene inlevereisen (link volgt).
