Les 2.8 — Feature Engineering

Ruwe data omzetten naar numerieke features waarmee een model kan werken: categorische features, tekst-features, afgeleide features en het omgaan met ontbrekende waarden.

Terugblik

In les 2.7 bepaalden we sentiment op financieel nieuws.

Vandaag

Feature engineering: de stap die vaak het meeste verschil maakt in een ML-project. We behandelen categorische features (one-hot encoding), tekst-features (count/TF-IDF), afgeleide features (zoals polynomiale) en imputatie van ontbrekende waarden — allemaal met scikit-learn.

Tekst-features Count en TF-IDF (CountVectorizer, TfidfVectorizer) — (notebook volgt)
