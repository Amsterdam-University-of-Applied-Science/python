Praktijk — class assignment

Bewerk met een coding agent een financiële tijdreeks en duid het patroon; de agent schrijft de code, het denkwerk is aan jou.

Aanpak: een tijdreeks ophalen (bijv. een koers of CBS/FRED-reeks) (10) · resampelen naar maand/kwartaal en een rolling average plotten — agent (15) · interpreteren (20) · conclusie (5).

Interpreteer: wat laat de rolling average zien dat de ruwe data niet toont (trend, seizoen, uitschieters), en welk resample-interval past bij je vraag? Wat zou je mis kunnen lezen?

Inleveren: notebook met code, de plot en je interpretatie — max 1 A4, volgens de algemene inlevereisen (link volgt).
