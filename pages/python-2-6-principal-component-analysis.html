Les 2.6 — Principal Component Analysis

PCA is een snelle, flexibele unsupervised techniek voor dimensionality reduction: het terugbrengen van het aantal variabelen.

Terugblik

In les 2.5 werkten we met tijdreeksen in pandas.

Vandaag

Principal Component Analysis. Anders dan regressie (die een y voorspelt uit x'en) zoekt PCA naar de sterkte van het verband tussen de variabelen onderling. Toepassingen: visualisatie, ruisonderdrukking en portfolioselectie.

Praktijk — class assignment

Pas met een coding agent PCA toe op een dataset met veel kolommen en interpreteer wat de componenten verklaren; de agent schrijft de code, het denkwerk is aan jou.

Aanpak: dataset met ≥4 numerieke kolommen kiezen (10) · PCA fitten en de verklaarde variantie per component tonen (explained_variance_ratio_) — agent (15) · interpreteren (20) · conclusie (5).

Interpreteer: hoeveel componenten heb je nodig voor ~90% van de variantie, wat betekent dat voor dimensiereductie, en wat verlies je door terug te brengen naar 2 componenten?

Inleveren: notebook met code, de variantie-plot en je interpretatie — max 1 A4, volgens de algemene inlevereisen (link volgt).
