Les 3.4 — Dashboards

Een interactief dashboard waarmee een gebruiker zelf door de data kan navigeren — zonder code te zien.

Terugblik

In les 3.3 bouwden we een herhaalbare datapijplijn.

Vandaag

We bouwen een financieel dashboard met Streamlit: grafieken, filters en keuzemenu's die de gebruiker zelf bedient.

Theorie

Onderwerp Toelichting Bron/notebook
Streamlit basis Van script naar web-app met één commando docs
Interactie Widgets: sliders, selecties, invoer —
Grafieken tonen pandas/plot-output in het dashboard —

Library — Streamlit. Documentatie

Verdieping:

  • Sweigart, A. (2020). Automate the boring stuff with Python (2nd ed.). No Starch Press. Output en presentatie

Praktijk — class assignment

Maak een dashboard met minstens één grafiek en één filter op een financiële dataset, zodat een gebruiker zelf een vraag kan beantwoorden.

Aanpak: dataset + vraag kiezen (10) · dashboard met grafiek + filter — agent (20) · uitproberen en bijschaven (15) · toelichting (5).

Inleveren: notebook of app met je product en een korte toelichting — max 1 A4, volgens de algemene inlevereisen (link volgt).
