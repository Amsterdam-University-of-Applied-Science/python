Les 3.5 — Rapportage automatiseren

Een terugkerend rapport (tear sheet, overzicht) dat zichzelf genereert als PDF of Excel — geen handwerk meer.

Terugblik

In les 3.4 bouwden we een interactief dashboard.

Vandaag

We automatiseren een rapport: data erin, een nette PDF/Excel eruit, elke keer hetzelfde en reproduceerbaar.

Theorie

Onderwerp Toelichting Bron/notebook
Rapport genereren Van data naar een opgemaakt document —
Excel/PDF schrijven Output die een gebruiker kan delen —
Herhaalbaar draaien Hetzelfde rapport, nieuwe data —

Library — pandas (export) & een rapport-/PDF-bibliotheek. Documentatie

Verdieping:

  • Sweigart, A. (2020). Automate the boring stuff with Python (2nd ed.). No Starch Press. Working with Excel/PDF

Praktijk — class assignment

Automatiseer een financieel rapport (bijv. een tear sheet) dat uit data een nette PDF of Excel maakt die je zonder aanpassing opnieuw kunt draaien.

Aanpak: rapportvorm kiezen (10) · generatie-script — agent (20) · opnieuw draaien met andere data (15) · toelichting (5).

Inleveren: notebook of app met je product en een korte toelichting — max 1 A4, volgens de algemene inlevereisen (link volgt).
