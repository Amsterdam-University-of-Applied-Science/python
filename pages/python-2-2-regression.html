Les 2.2 — Regression

Het voorspellen van een continue waarde: regression — predicting continuous labels. Van simpele lineaire regressie tot basis-functies en regularisatie.

Terugblik

In les 2.1 haalden we data op uit externe bronnen (CBS, FRED, IMF, Worldbank).

Vandaag

Onze eerste machine-learning-techniek: lineaire regressie met scikit-learn: simple linear regression, basis-functie-regressie (polynomiaal, Gaussian) en regularisatie (Ridge, Lasso).

Praktijk — class assignment

Bouw met een coding agent een lineair regressiemodel en interpreteer het; de agent schrijft de code, het denkwerk is aan jou.

Aanpak: data van CBS/FRED kiezen (10) · model + plot door agent (10) · interpreteren (20) · conclusie (10).

Interpreteer: wat betekent de coëfficiënt economisch, wat zegt de R² over de fit, en is het verband plausibel of zie je een valkuil? Sluit af met: zou je hierop een financiële beslissing baseren?

Inleveren: notebook met code, plot en analyse — max 1 A4, volgens de algemene inlevereisen (link volgt).
