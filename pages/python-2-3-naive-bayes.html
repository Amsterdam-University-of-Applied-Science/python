Les 2.3 — Naive Bayes

Classificatie: identifying which category an object belongs to. Naive Bayes-classificatie met scikit-learn.

Terugblik

In les 2.2 voorspelden we continue waarden met lineaire regressie.

Vandaag

We stappen van regressie naar classificatie. Naive Bayes is een snelle, supervised techniek. In scikit-learn: GaussianNB (continue data), MultinomialNB (teldata) en BernoulliNB (binaire data).
