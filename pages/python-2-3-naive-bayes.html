Naive Bayes Classification (NBC)

Classification: Identifying which category an object belongs to.

Scikit-Lean bevat verschillende NBC methods. Dit zijn supervised learning algoritmes. In Scikit-Learn treffen we o.a. de volgende NBC modellen:

  • GaussianNB (applied in case of continuous data)
  • MultinomialNB (applied in case of count data)
  • BernoulliNB (applied in case of binary data)

Datasets die worden meegeleverd met de Seaborn library:

import seaborn as sns
sns.get_datasets_names()

Datasets die worden meegeleverd met de Sklearn library:

from sklearn import datasets
iris = datasets.load_iris()
